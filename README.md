# Lumi 🐾
### Turn your daily content observations into visible personal growth.

Lumi 是一个为小红书内容生态观察者设计的轻量洞察积累工具。  
它帮助产品、运营、风控等内容相关同学，在日常浏览内容时，用最低成本把判断留下来——然后慢慢看见自己在变厉害。

---

## 为什么做 Lumi

内容人每天都在产生大量内容判断，但这些判断是无形的。  
它们存在于刷内容的那一刻，然后消散。  
三个月后写报告，脑子里是空的。  
老员工离职，经验带走了，新人只能重新踩坑。

现有工具（飞书文档、Notion）的问题不是功能不够，而是**门槛太高、和内容人的工作节奏不匹配**。  
大多数人干脆不记录。

Lumi 的逻辑是：**不要求你规范，只要求你随手记一句话。**  
剩下的，交给 AI，交给你的宠物，交给时间。

---

## 核心功能

### 📝 Workspace — 录入与分析
- 粘贴笔记链接、标题、正文（三选一，加上必填的一句话观察）
- 点击 **Analyze with Lumi**，AI 自动输出：
  - 内容摘要
  - 内容类型
  - 观察视角
  - 洞察标签
- 提供 **5 条真实小红书样例模板**，可随机加载体验完整流程

### 🐾 Pet Companion — 宠物成长系统
选择你的陪伴物：**小猫 / 小狗 / 纸盒子 / 一瓶可乐**  
每次完成观察录入，宠物获得 XP，逐渐解锁专属技能称号：

| 技能 | 含义 |
|------|------|
| 评论区猎手 | 善于从评论区发现正文之外的真实信号 |
| 情绪捕手 | 能感知内容中的情绪驱动力 |
| 商业嗅觉 | 能识别内容背后的品牌与变现逻辑 |
| 趋势雷达 | 能从碎片中捕捉内容生态的变化方向 |
| 风险边界感 | 能识别内容中潜在的平台风险信号 |

### 📖 Journal — 个人观察轨迹
按时间顺序保存你所有的观察记录。  
每条记录以**你的一句话观察**为主角，AI 标签为辅助。  
这不是知识库，是你的判断力成长轨迹。

### 🏆 Community — 技能社区
- **颁奖台排行榜**：技能最多的人、某项技能熟练度最高的人，和你的宠物并排展示
- **技能板块讨论区**：按技能类型划分，习得对应技能才能进入，贴吧式论坛风格

## 产品设计亮点

**为什么是宠物？**  
因为"维护知识库"是有心理负担的事，但"喂宠物"没有负担。  
宠物把记录这件事变成了一种自然的日常，而不是一项任务。

**为什么技能按观察视角命名，而不是内容品类？**  
你看的内容可以很杂——美食、美妆、职场、宠物都可以。  
但 Lumi 积累的不是"你看了什么"，而是"你习惯用什么视角看内容"。  
技能描述的是你这个人，不是你看的内容。

**为什么没有"一键生成报告"？**  
因为一旦有了生成报告，这就变成了另一个 AI 聊天工具。  
Lumi 的价值在过程，不在输出端。

## 技术说明

- 纯前端 Demo，无后端，无数据库，无登录
- 状态管理使用浏览器内存态
- AI 分析为 Demo 阶段预置逻辑，真实样本数据来自小红书真实笔记
- 响应式布局，支持桌面三栏视图与移动端底部导航

---

## Demo 体验路径

1. 选择你的陪伴物，给它起名字
2. 在 Workspace 点击 **"试试样例模板"**，随机加载一条真实小红书笔记
3. 点击 **"Analyze with Lumi"**，查看 AI 分析结果
4. 观察宠物 XP 增长，等待技能解锁
5. 切换到 **Journal** 查看观察记录
6. 切换到 **Community** 查看技能排行榜和讨论板块
