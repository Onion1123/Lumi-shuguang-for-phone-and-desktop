# 薯光 Lumi 🌟
### 把内容人每天无形的判断，变成可见的个人成长。

> "Lumi 不替你做判断，它帮你记住判断。"

**Demo 链接：** https://insight-growth-pet.lovable.app/

---

## 项目背景

本项目为小红书 Red Finance Trainee Builder Test 48小时挑战作品。  
从发现问题 → 产品定义 → Demo 交付，全程独立完成。

---

## 我观察到的问题

内容从业者每天都在产生大量内容判断——

- 刷到一条有意思的笔记，觉得"这个评论区有问题"
- 看到一个品牌的投放策略在悄悄变化
- 感觉某类内容的情绪浓度在上升

但这些判断是无形的。它们存在于刷内容的那一刻，然后消散。  
三个月后要写报告，脑子里是空的。  
老员工离职，经验带走了，新人只能重新踩坑。

现有工具（飞书、Notion）不是不能记录，是**门槛和工作节奏不匹配**。  
内容人的工作是碎片化的、感性的、快节奏的——坐下来认真整理这件事，大多数人干脆放弃了。

---

## Lumi 的解法

**一条内容 + 一句话观察，10 秒完成录入。**

AI 帮你提炼观察视角和洞察标签。  
宠物陪伴成长，让积累这件事有即时反馈。  
技能系统让你慢慢看见自己的判断能力在变强。

Lumi 积累的不是内容，而是**你观察内容的方式**。

## 核心功能

### 🧠 Workspace — 录入与分析
- 粘贴笔记链接、标题或正文（三选一）+ 必填的一句话观察
- 点击 **Analyze with Lumi**，AI 输出：
  - 内容摘要
  - 内容类型
  - 观察视角
  - 洞察标签
- **"试试样例模板"** 按钮随机加载 5 条真实小红书笔记，可直接体验完整流程

### 🐾 Pet Companion — 宠物成长
选择你的陪伴物：**小猫 / 小狗 / 纸盒子 / 一瓶可乐**  
每次完成观察录入，宠物获得 XP，逐渐解锁专属技能称号：

| 技能 | 含义 |
|------|------|
| 评论区猎手 Comment Hunter | 善于从评论区发现正文之外的真实信号 |
| 情绪捕手 Emotion Catcher | 能感知内容中的情绪驱动力 |
| 商业嗅觉 Commercial Instinct | 能识别内容背后的品牌与变现逻辑 |
| 趋势雷达 Trend Radar | 能从碎片中捕捉内容生态的变化方向 |
| 风险边界感 Risk Sensor | 能识别内容中潜在的平台风险信号 |

技能命名的逻辑：不是"你看了什么品类"，而是"你习惯用什么视角看内容"。

### 📖 Journal — 观察轨迹
按时间顺序保存所有观察记录，最新在前。  
每条记录以**你的一句话观察**为主角，AI 标签为辅助。  
这不是知识库，是你的判断力成长轨迹。

### 🏆 Community — 技能社区
- **颁奖台排行榜**：技能最多的人、某项技能熟练度最高的人，和你的宠物并排展示
- **技能板块讨论区**：按技能类型划分，习得对应技能才能进入，贴吧式论坛风格

## 产品设计决策

**为什么是宠物？**  
"维护知识库"是有心理负担的事，但"喂宠物"没有负担。宠物把记录这件事变成了自然的日常，而不是一项任务。

**为什么技能按观察视角命名，而不是内容品类？**  
你看的内容可以很杂——美食、美妆、职场都行。Lumi 积累的不是"你看了什么"，而是"你习惯用什么角度看内容"。技能描述的是你这个人。

**为什么没有"一键生成报告"？**  
因为那会让它变成另一个 AI 聊天工具。Lumi 的价值在过程，不在输出端。

## 技术路径

| 层 | 工具 | 决策原因 |
|---|---|---|
| 前端生成 | Lovable | AI 驱动，自然语言 prompt 直接生成 React 应用，零开发经验可用 |
| 部署 | Lovable 自动部署 | 一键生成公开链接，无需配置服务器 |
| 代码托管 | GitHub | 版本管理，评审可查看源码 |
| AI 分析 | 预置逻辑（Demo 阶段） | 规避现场 API 失败风险，使用真实笔记数据保证内容真实性 |
| 数据存储 | 浏览器内存态 | 无后端、无数据库，48小时内最稳定的方案 |

**关于 AI 分析的实现：**  
Demo 阶段使用预置的真实数据，而非实时 API 调用。5 条样本均来自真实小红书笔记，AI 分析内容为人工标注。真实产品版本将接入 LLM API 实现实时分析。

---

## 已知局限与下一步

**当前局限：**
- AI 分析为预置逻辑，不支持任意链接的实时解析
- 数据不持久化，刷新页面后记录消失
- Community 为静态展示，不支持真实多用户交互

**如果继续迭代：**
- 接入 LLM API 实现真实内容解析
- 加入账号系统和云端数据同步
- 探索"团队判断力地图"——多人使用时，团队的技能分布会形成集体观察能力的可视化
